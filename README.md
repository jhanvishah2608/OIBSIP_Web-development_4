# OIBSIP_Web-development_4

--Objective:
To develop a basic login authentication webpage that verifies user credentials and provides secure access to the system.

--Steps Performed:

1. Created the login form structure using HTML.
2. Added input fields for username and password.
3. Used JavaScript to validate user credentials and handle authentication logic.
4. Applied CSS styling to create a clean and responsive user interface.

--Tools Used:

* HTML
* CSS
* JavaScript
* VS Code

--Outcome:
The login authentication system successfully validates user login details and demonstrates the basic concept of user authentication in web development.
